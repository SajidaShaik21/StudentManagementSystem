STUDENT MANAGEMENT SYSTEM - CORE JAVA MINI PROJECT

Requirements:
- JDK 8 or later
- VS Code / any Java IDE (optional)

Files:
- Main.java
- Person.java
- Student.java
- StudentOperations.java
- StudentManager.java
- InvalidStudentException.java
- DuplicateStudentException.java

Compile:
    javac *.java

Run:
    java Main

Features:
1. Add student
2. Display all students
3. Search by student ID
4. Update student details
5. Delete student
6. Calculate grade
7. Validate inputs and prevent duplicate IDs

Grade scale:
90-100: A+
80-89: A
70-79: B
60-69: C
50-59: D
Below 50: Fail

Note:
This is an in-memory console application. Records are cleared when the
program exits because file/database storage is not part of this version.
